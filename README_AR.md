# HashVista 1.3.0 — دليل الاستخدام

HashVista برنامج Windows x64 محلي لجرد الملفات، وحساب هاش الملف كاملًا، واستخراج بيانات وبصمات الصور والفيديو، وتصدير النتائج إلى CSV. يقرأ الملفات الأصلية دون تعديلها. لا يتضمن مقارنة الملفات أو البحث عن المتكررات أو تجميع المتشابهات أو الحذف والنقل.

## أي حزمة أستخدم؟

- **الحزمة العامة Core:** تعمل بالضغط على `HashVista.exe`، وتضم محرك الجرد والهاش والتصدير وبيئة .NET. لا تحتاج SDK أو Terminal للتشغيل. أدوات الوسائط الخارجية ليست مضمنة؛ يظهر غيابها صراحةً عند طلبها.
- **الحزمة المحلية الكاملة:** تتضمن أدوات الوسائط المستخدمة في الاختبارات. هي منفصلة عن الحزمة المعدة للنشر العام؛ راجع `THIRD_PARTY_NOTICES.md` قبل إعادة توزيع أدواتها.

فك الحزمة كاملة في مجلد قابل للكتابة. لا تنقل EXE وحده. النشر العام يستخدم الحزمة العامة والمصدر المنقّى المرافق لها، لا مجلد التطوير أو الحزم التاريخية.

## خطوات الفحص

1. اختر الجذور من تبويب **Browse** بوضع علامة على المجلد أو القرص، أو استخدم **Add files / Add folder**. يمكن سحب المدخلات إلى النافذة. تبويب **Selected** يعرض القائمة الفعلية؛ **Remove selected / Clear input list** يزيل المدخلات من القائمة فقط.
2. اختر الهاشات المطلوبة. **SHA256** هو الافتراضي، و**SHA512 / SHA1 / MD5** خيارات فعلية إضافية تُحسب في قراءة متدفقة واحدة. أعمدة النتائج تتبع الخوارزميات المختارة. لا توجد خوارزميات إضافية غير منفذة في الواجهة.
3. افتح **Media options** فقط إذا احتجت بيانات الوسائط أو بصماتها أو هاش المسارات المشفرة. هذه المراحل اختيارية ومغلقة افتراضيًا.
4. اضغط **Start new scan** واختر اسم قاعدة جديدة بامتداد `.ghscan`. تُحفظ النتائج تدريجيًا وتظهر في جدول النتائج أثناء العمل.
5. بعد الانتهاء أو **Cancel**، راجع الصفوف والتفاصيل ثم اختر **Export all results** أو **Export filtered results**، واحفظ التقرير خارج جذور الفحص.

شجرة المجلدات تقرأ المستوى الذي تفتحه عند الطلب وتعرض حتى 500 مجلد فرعي لكل توسعة. إذا ظهرت **More folders: use Add folder** فاستخدم اختيار المجلد المباشر. هذا حد لعرض الشجرة فقط؛ لا يحدّ عدد الملفات التي يفحصها المحرك.

## الإيقاف والمتابعة والحفظ

| الأمر | ما يفعله |
|---|---|
| **Pause** | يطلب توقفًا مؤقتًا عند نقطة آمنة. أثناء قراءة ملف يُحتفظ بحالة الهاش في الذاكرة؛ قد ينتظر عملية وسائط أو استدعاء نظام ملفات جارٍ. |
| **Continue** | يكمل الجولة نفسها بعد Pause دون إعادة حساب ما أنجزته تلك الجولة. |
| **Cancel** | ينهي الجولة ويحفظ النتائج الجزئية القابلة للعرض والتصدير. |
| **Open saved scan** | يفتح النتائج المحفوظة دون إعادة حسابها. |
| **Resume / refresh scan** | يبدأ تعدادًا وحسابًا جديدين لجميع ملفات القاعدة بالإعدادات المحفوظة، مع إبطال النتائج السابقة قبل تحديثها. |

**Continue** يخص جلسة مفتوحة ومتوقفة مؤقتًا. بعد إغلاق البرنامج أو انقطاعه لا يُستعاد موضع القراءة داخل الملف؛ تظهر الجولة غير المنتهية **Interrupted**، ويعيد **Resume / refresh scan** الحساب. لتغيير الخيارات افتح فحصًا جديدًا. ملف `.ghscan` يُفتح بزر **Open saved scan**؛ إضافته كملف إدخال لا تستأنف محتواه.

ملفات الفحص المحفوظة تستخدم الامتداد `.ghscan`.

## النتائج والتقدم والتصفية

- **All files / Images / Videos / Other** وقائمة **All disks / Disk # / Unknown disk** ترشّحان النتائج الموجودة، ولا تغيّران نطاق الجولة. رقم القرص هو الهوية التي استطاع Windows إرجاعها؛ قد يبقى مجهولًا لبعض الأجهزة والمشاركات.
- العرض صفحات من 250 صفًا. **Previous / Next** يتنقلان بين الصفحات. تُحمّل الصفحات خارج مسار الواجهة، ويُحافَظ على تحديد الصف عند تحديث الصفحة ما دام ضمنها.
- **Actually read** يبيّن البايتات المقروءة لحساب هاش الملفات؛ **Read rate** سرعة تلك القراءة في الفترة الأخيرة، وليست سرعة فك الوسائط أو معدلًا مضمونًا. الوحدات ثنائية: KiB وMiB وGiB وTiB.
- يبدأ الهاش بعد انتهاء التعداد. خلال **INVENTORY** تظهر الملفات المكتشفة والمجلد الجاري؛ لا تُعرض نسبة نهائية قبل معرفة الإجمالي. لا توجد قراءة متوازية جديدة لملفات متعددة أو ذاكرة هاش تتجاوز قراءة المحتوى في هذا الإصدار.
- **Traversal issues** يعرض أول 1,000 مشكلة أو استبعاد؛ القائمة الكاملة في ملف التصدير المصاحب. الصفر يعرض **NO FILES SCANNED** والسبب المتاح، لا نجاحًا بنسبة 100%.

الجذور المختارة صراحة تدخل الفحص حتى إن حملت Hidden/System؛ تبقى سياسة **Include hidden / Include system** مطبقة على محتوياتها. **Recursive folders** يضم المجلدات الفرعية، و**Follow links (loop-safe)** يتحكم بالروابط. الجذور المتداخلة لا تكرر المسار نفسه، لكن نسخ الملف بأسماء مختلفة تبقى سجلات منفصلة.

## التصدير والمعاينة

**Export all results** يصدر كل الصفوف المحفوظة، بصرف النظر عن الصفحة أو المرشح أو التحديد. **Export filtered results** يصدر جميع الصفوف المطابقة لنوع الملف ورقم القرص المختارين، لا الصفحة المرئية وحدها. يتضمن كلاهما الصفوف الفاشلة والجزئية، ولا يعيد حساب الهاش. لا يُصدّر أثناء الفحص أو Pause؛ أنهِ الجولة أو ألغها أولًا.

التقرير UTF-8 مع BOM، ويحفظ العربية والفواصل والاقتباسات والأسطر في الحقول. احتفظ بملفي `report.csv` و`report.csv.scan.json` معًا؛ يسجل المصاحب الخيارات والحالة والمرشح وعدد الصفوف ومشكلات التعداد. فراغ رقم القرص يعني «مجهول» عند اختيار ذلك المرشح، بينما `null` في وصف المرشح يعني جميع الأقراص. عند الاستيراد إلى جدول بيانات عيّن الهاشات كنص.

**Copy hash** ينسخ هاش الصف، و**Copy selected rows** ينسخ الصفوف المحددة من الصفحة الحالية. قسم **Selected file details & preview** يعرض التفاصيل والمعاينة عند تحديد ملف وبعد انتهاء الجولة أو إلغائها. المعاينة تقرأ الملف الموجود حاليًا؛ ليست نسخة محفوظة لوقت الفحص.

## أدوات الوسائط ومعاني البصمات

تحتاج الوسائط إلى `ffmpeg.exe` و`ffprobe.exe` و`exiftool.exe` داخل `dependencies` بجانب البرنامج، مع مجلد `exiftool_files` الكامل لحزمة ExifTool. تحقق من **Tools & profiles**. الحصول على الأدوات من مصادرها الأصلية وخطوات الإعداد مذكورة في `BUILD.md`. غيابها أو عدم دعم صيغة لا يمنع الهاش العادي.

- `SHA256` هاش بايتات الملف كاملًا. `ImagePixelSHA256` هاش صورة مفكوكة ومطبّعة إلى 256×256 RGB، بعد اتجاه EXIF وتركيب الشفافية على الأسود. `PerceptualHash` بصمة إدراكية 64 بت؛ لا تقارنها هذه الواجهة بين الملفات.
- الصور المتحركة ومتعددة الصفحات تستخدم الإطار أو الصفحة الأولى. RAW يستخدم JPEG مضمنًا إن توفر ويسجل `PixelSource=EmbeddedPreview`؛ لا يوجد فك كامل لبيانات مستشعر الكاميرا.
- الفيديو يستخدم ست نقاط محددة في `MEDIA_PROFILES.md`. يسجل وقت الطلب؛ وقت الإطار الفعلي `ActualSeconds` يبقى فارغًا لأنه غير مقاس.
- **Video/audio stream SHA-256 (encoded)** يحسب بيانات المسارات المشفرة المنسوخة من الفيديو. ليس هاش الحاوية أو هاش العينات بعد فك الترميز. لا يوجد وضع مستقل جديد لفهرسة وسوم ملفات الصوت.

حالات Hash وMetadata وFingerprint وStreamHash مستقلة. فشل الوسائط لا يمحو هاشًا ناجحًا. **ChangedDuringScan** يعني اكتشاف تغير الحجم أو وقت التعديل؛ هذا ليس ضمان لقطة ثابتة لنظام الملفات. المجهول يبقى فارغًا، وحجم الملف الفارغ المعروف يساوي صفرًا.

البيانات المحلية في `Data/scans` و`Data/cache`. أغلق البرنامج قبل نقل `Data` مع قواعده. تستخدم القاعدة WAL/NORMAL؛ قد تضيع أحدث تحديثات النتائج عند انقطاع الكهرباء المفاجئ، دون تعديل ملفات المصدر. `VERIFICATION.md` يحدد اختبارات هذه النسخة وحدودها، و`MEDIA_PROFILES.md` يشرح تفاصيل الترميز والبصمات.
